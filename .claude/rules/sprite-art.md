# Sprite Art Rules

- Before creating or changing any sprite, read `design/art/sprite-style-guide.md` and the study cards it points to
- New visual style or asset family: run a reference study first (`tools/sprites/study_ref.py`) and write a style card before building
- Measure finished sprites with the same study script and compare against the style card — numbers, not impressions
- Never commit third-party reference sheets; commit only our measurements, cards and rules
