# Study: Terraria sword progression — how "better" reads

- **source**: terraria.wiki.gg item images via Special:FilePath (Copper Shortsword → Iron/Gold/Platinum Broadsword → Night's Edge → Excalibur → True Excalibur → Terra Blade → Zenith) · studied: 2026-11-15
- **true size**: ~16–50px · **colors**: 17 per sword (low tiers ~6–8, top tiers 20+)
- **subject**: one item type across the whole progression curve

## Measurements
- outline: dark coloured (black 7%); inner lines 22%; 1px runs 91% (very crisp)
- dithering 6.6% and a little semi-alpha — used for glow/sparkle on high tiers only
- light from the top

## Observations — the tier ladder
1. basic metals: same simple silhouette, only the hue changes (copper → iron → gold → platinum)
2. mid tier: new silhouette features (crossguard shapes, jewels in the hilt)
3. high tier: saturated signature colour (green, gold, cyan), gems, glow pixels, more colours
4. top tier: biggest size, most complex silhouette, multi-colour, glow
- size, colour count and saturation all rise together with tier

## Rules to apply (core rule for idle-game upgrades)
- Tier 1–4: same shape, swap material hue
- Tier 5+: add silhouette features (guards, gems, spikes)
- Top tiers: larger sprite, signature saturated colour, 1–3 glow/sparkle pixels, more colours
- Never make a higher tier smaller or duller than the one before
