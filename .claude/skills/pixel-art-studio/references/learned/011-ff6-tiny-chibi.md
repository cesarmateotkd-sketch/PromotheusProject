# Study: Final Fantasy VI field sprites — tiny chibi readability

- **source**: Spriters Resource "Terra Branford - FF6" (SNES), native-size page screenshot · studied: 2026-11-15
- **true size**: ~19x27px characters (34 sprites) · **colors**: 11 per sprite
- **subject**: field/battle sprites where a character is barely 2 heads tall

## Measurements
- outline: no pure black — dark coloured (edge lum 0.18 vs interior 0.40)
- inner lines 25% (high: at this size lines define the form); 1px runs 72%; dithering 2.5%
- light from the left; hue shift +7° (warm highlights)

## Observations
- ~2 heads tall; hair colour and one costume colour carry identity; face = 2 dark pixels
- poses are exaggerated because there are so few pixels to show them

## Rules to apply
- Below ~32px: identity = hair colour + one costume colour + silhouette; exaggerate poses
- Use dark coloured outlines and a high share of interior line pixels to separate parts

## Do NOT copy
- SNES palette limits (15 colours per sprite) as a goal in itself — use them only if the look needs it
