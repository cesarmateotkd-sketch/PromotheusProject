# Study: Legends of IdleOn class sprites — modular characters for an idle game

- **source**: idleon.wiki class images (12 classes) via the MediaWiki file API · studied: 2026-11-15
- **true size**: ~100x90px · **colors**: 18 per sprite, 162 across classes
- **subject**: an idle MMO's class roster

## Measurements
- outline: 86% black/near-black
- inner lines 11%; 1px runs 48%; dithering 1%; saturation 0.47; hue shift +9°

## Observations
- every class uses the same blank white template body/head (no face); identity comes entirely from gear, weapon and colour
- gear is detailed and painterly; the body is deliberately featureless
- weapons are oversized and extend the silhouette (axes, staves, bows)

## Rules to apply
- For an idle game with many classes/upgrades: build ONE template body and layer gear/weapons/colour on it — huge variety at low cost, consistent proportions
- Put detail in the upgradeable items, not in the base body
- Oversize weapons and hats so class reads instantly at small size

## Do NOT copy
- The faceless look unless it suits the game's tone; it trades personality for flexibility
